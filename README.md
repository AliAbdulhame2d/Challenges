### 2. ☀️ Sun Rays
* **Description:** A clever and out-of-the-box approach to creating sun rays. Instead of using complex SVGs or gradients, the rays are constructed using massive, rotated text characters (`+`) layered perfectly behind a CSS-styled circle.
* **Technologies:** HTML Divs, CSS Positioning (`absolute`/`relative`), `z-index` layering, Typography scaling (`font-size`), and CSS `rotate`.

### 3.  Pure CSS Car
* **Description:** A fun **CSS Art** challenge! Drawing a minimalist car completely from scratch using only a well-structured layout of HTML `div` elements and CSS shapes, without relying on any external images.
* **Technologies:** CSS Flexbox, Absolute & Relative Positioning, basic geometry, and `border-radius`.

### 4.  Animated "Hello World" (Blend Mode Effect)
* **Description:** A dynamic text effect where an animated shape moves continuously across the screen. By utilizing CSS blend modes, the colors of the text and the moving shape invert wherever they overlap, creating a beautiful and smooth masking illusion.
* **Technologies:** CSS Keyframe Animations (`@keyframes`), Pseudo-elements (`::before`, `::after`), `mix-blend-mode: difference`, and `transform`.
